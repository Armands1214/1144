RĪGAS SATIKSME NEXT — V3 (neoficiāls dizaina koncepts)

1. Atarhivē ZIP.
2. Terminālī šajā mapē palaid: python -m http.server 8000
3. Atver http://localhost:8000/ (sākumlapa) vai http://localhost:8000/karte.html (karte).

Karte izmanto Leaflet un OpenStreetMap kartes flīzes, tādēļ vajadzīgs internets.
GTFS dati ir statiski. Kustības laiki nav GPS reāllaika prognozes.
Nav calendar.txt; datumam piesaistītie saraksti nav pilnībā verificēti.
shapes.json ir izveidots no augšupielādētā shapes.txt, sasaistīts ar trips.txt.
Pieturas attēlotas no viena reprezentatīva garākā reisa attiecīgajā virzienā; atsevišķos reisu variantos pieturas var atšķirties.
Šis nav oficiāls Rīgas satiksmes produkts.
